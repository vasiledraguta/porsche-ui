# Porsche UI

Porsche UI is a web concept of the Porsche PCM with a 3D 911 GT3 RS.

```bash
bun install
bun dev
```

Needs Node.js 20.9+.

## Controls

W / ↑ throttle · S / ↓ brake · A demo drive · M drive mode · Space play/pause · ← / → tracks · H home · Esc close · ? shortcuts
